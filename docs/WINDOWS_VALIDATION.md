# Ручная проверка Windows 10/11

Статус: не выполнена в облачном Linux-окружении. Заполнять фактические результаты,
версию Windows, CPU, устройства и версии зависимостей после проверки на Windows.

- [ ] Установка в чистом Python 3.11 x64; загрузка моделей; запуск без сети после загрузки.
- [ ] Микрофон: «Wann haben Sie morgen Zeit?» → немецкий текст и осмысленный русский перевод.
- [ ] Loopback: воспроизвести немецкий WAV в плеере; убедиться, что микрофон выключен.
- [ ] Оба источника: раздельные метки, отсутствие взаимного загрязнения VAD.
- [ ] 30 секунд тишины: нет постоянных ложных субтитров.
- [ ] Длинная реплика, паузы, быстрый разговор; измерить задержку и повторы на границах.
- [ ] Отключённый микрофон / смена устройства: видимое сообщение об ошибке, возможность перезапуска.
- [ ] Все три режима, светлая/тёмная темы, перенос Overlay на второй монитор.
- [ ] Трей: закрытие окна сохраняет захват; горячие клавиши работают вне приложения.
- [ ] Конфликт горячей клавиши отображается; после выхода регистрация освобождается.
- [ ] Private Mode: успешный API и фактический результат в Snipping Tool, OBS Window/Display Capture,
      Teams/Zoom screen share. Для каждого отдельно указать версию и результат.
- [ ] Основное окно свёрнуто при проверке Private Mode. Выключение режима возвращает захват Overlay.
- [ ] Ollama: A1/A2/B1/B2, русский перевод, IPA, немецкий системный голос.
- [ ] Выключенный Ollama не блокирует субтитры; ошибка видна в помощнике.
- [ ] Выход во время распознавания/генерации корректно ожидает завершения, процесс исчезает.
- [ ] Распакованный CI-артефакт на чистой Windows без Python: --help, --setup-models, живой захват.
- [ ] Нет файлов аудио и разговоров после сессии (кэши моделей допустимы).
