# LiveTranslate

Рабочий MVP локальных немецко-русских субтитров для Windows 10/11 x64.
Python 3.11/3.12, PySide6, PyAudioWPatch (WASAPI), Silero VAD ONNX,
faster-whisper CPU int8, Argos Translate. Облачная среда нужна для разработки
и CI; включённый домашний компьютер не нужен. Само приложение запускается
на Windows, где находятся аудио и окна.

## Установка и запуск (PowerShell)

Установите Python 3.11 x64 и Microsoft Visual C++ Redistributable 2015–2022 x64.
Из каталога проекта:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install -e ".[dev]"
python -m livetranslate --setup-models
python -m livetranslate
```

Если PowerShell блокирует активацию, вызывайте `.venv\Scripts\python.exe`
напрямую. Установка моделей требует интернета и места на диске. Whisper base
загружается с Hugging Face, пакеты Argos de→en и en→ru — из каталога Argos.
Модели хранятся в стандартных пользовательских кэшах библиотек, не в Git.
Silero поставляется с пакетом. Модели имеют собственные лицензии.
Первый выбор tiny/small также скачивает соответствующую модель Whisper.
После загрузки выбранных моделей распознавание и перевод работают локально.
Короткий фрагмент передаётся CTranslate2 целиком с токенизатором Argos, без загрузки дополнительных моделей разделения предложений.

1. Разрешите доступ к микрофону для классических приложений в Windows.
2. Выберите системное аудио, микрофон или оба источника; при необходимости
   укажите конкретное устройство в списке. Подключённые после запуска устройства
   требуют перезапуска приложения. При смене динамиков остановите захват и начните заново.
3. Нажмите **Начать**. Произнесите немецкую фразу или воспроизведите немецкую речь.
4. Перетащите Overlay мышью в удобное место. Последняя реплика исчезает через 15 секунд.
5. Закрытие основного окна сворачивает приложение в трей. Для завершения выберите
   **Выход** в трее. Остановка/выход ожидает окончания текущего вычисления.

Используйте наушники при одновременном захвате: иначе микрофон может повторно
захватить звук динамиков. Акустическое эхоподавление и разделение говорящих
в MVP не реализованы. При синтезе немецкого ответа системный захват также может
его распознать — на время произношения остановите прослушивание.

## Режимы и управление

### Одновременный захват микрофона и системного звука

Оба читателя используют общий экземпляр PyAudio с синхронизированной
инициализацией и завершением PortAudio. Каждый рабочий поток также
инициализирует COM для WASAPI. Это устраняет гонку при включении обоих
источников, вызывавшую нативный abort с assertion в `pa_front.c`, а также
ошибку открытия WASAPI из потока без COM. Устройства и настройки защиты
Windows менять не требуется.

| Режим | Субтитры |
|---|---|
| Full Translation | Немецкий оригинал и русский перевод |
| Smart Listening | Немецкий текст, выделенные слова из учебного словаря, значения и подсказки о типе вопроса |
| German Only | Только немецкий оригинал |

Smart Listening — прозрачные словарные эвристики, не полное семантическое
понимание. Словарь и правила расширяются в `core.py`.

| Горячая клавиша | Действие |
|---|---|
| Ctrl+Alt+S | Начать / остановить |
| Ctrl+Alt+O | Показать / скрыть Overlay |
| Ctrl+Alt+P | Переключить Private Overlay |

Горячие клавиши глобальные через RegisterHotKey; конфликт регистрации отображается
в интерфейсе. Есть светлая/тёмная тема. Overlay имеет полупрозрачную подложку,
остаётся поверх обычных окон, но может не отображаться поверх эксклюзивного fullscreen.

## Private Overlay Mode

Используется `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)` только для
окна субтитров. Приложение проверяет код возврата и читает affinity обратно.
Требуется Windows 10 2004 (build 19041) или новее. До этого режима чекбокс выключен.
Проверка API подтверждает настройку Windows, а не результат конкретного рекордера.

Это исключение из **поддерживаемых** способов захвата, а не DRM и не гарантия:
драйверы, удалённый доступ, сторонние рекордеры или внешняя камера могут вести себя
иначе. Проверьте используемый способ захвата. Основное окно с предпросмотром
и помощником не исключается — сверните его в трей при демонстрации экрана.
При ошибке API режим не обозначается как включённый.

## Помощник ответов A1–B2

Для генерации нужен локальный [Ollama](https://ollama.com):

```powershell
ollama pull qwen2.5:3b
ollama serve
```

Если Ollama уже запущен в трее, повторный `serve` не требуется. Введите смысл
ответа по-русски, выберите A1/A2/B1/B2 и нажмите **Сформулировать**. Запрос идёт
только на `127.0.0.1:11434`, без HTTP-прокси. Можно указать другую установленную
модель. Вывод содержит немецкий ответ, перевод, IPA и учебную подсказку.
Уровень и IPA генерирует LLM: возможны ошибки, соответствие CEFR не сертифицировано.
Без Ollama субтитры продолжают работать; помощник покажет ошибку подключения.
Для кнопки произношения установите немецкий голос Windows (Параметры → Время
и язык → Речь). Используется локальный QtTextToSpeech/системный голос.

## Задержка и ограничения MVP

Аудио переводится в mono 16 kHz потоковым soxr. Silero получает кадры по 32 мс;
конец реплики определяется после 448 мс тишины. Длинная речь делится каждые
примерно 4 секунды с 192 мс перекрытием; у границ возможны повторы слов.
Это near-real-time перевод завершённых фрагментов, не пословный streaming.
Время распознавания/перевода зависит от CPU. В UI указана задержка **после
завершения фрагмента**, без времени накопления фрагмента.

Очередь ограничена тремя репликами. При перегрузке старая реплика пропускается
с предупреждением; фрагменты старше 8 секунд не обрабатываются. Для меньшей
задержки выберите tiny или один источник, для точности — small на более мощном CPU.
Whisper может ошибаться и галлюцинировать; VAD и фильтр no_speech снижают риск,
но не устраняют его. Перевод через английский может терять смысл.
GPU/CUDA, автоматическое эхоподавление и инкрементальный пересмотр гипотез —
следующие этапы; текущий MVP использует CPU для простой воспроизводимой установки.

## Приватность

Приложение не пишет аудио, субтитры, ответы или историю на диск, не содержит
телеметрии, API-ключей и облачного API. Аудиобуферы и последняя реплика находятся
в RAM. Настройки также не сохраняются. При остановке предпросмотр очищается;
введённый ответ остаётся в окне до завершения процесса. ОС может использовать
swap/crash dumps. Кэши моделей и пакетов сохраняются библиотеками.
Текст в Ollama отправляется только по кнопке и только введённый пользователем;
хранение и логи самого Ollama регулируются отдельно.

## Тестирование и сборка

```powershell
python -m pytest -q
ruff check src tests
```

Linux-тесты проверяют VAD-сегментацию на заданных вероятностях, ограничение очереди,
режимы, экранирование HTML, контракт локального помощника. Qt smoke test запускается
с `QT_QPA_PLATFORM=offscreen`. Они **не подтверждают** реальное качество распознавания,
микрофон, WASAPI, глобальные горячие клавиши или исключение из захвата.
Сценарии ручной проверки: [docs/WINDOWS_VALIDATION.md](docs/WINDOWS_VALIDATION.md).

GitHub Actions (`.github/workflows/build.yml`) запускает тесты Linux/Windows и
PyInstaller на Windows x64. Артефакт **LiveTranslate-Windows-x64** содержит
`LiveTranslate.exe` **вместе с папкой `_internal`**. Распакуйте весь архив:

```powershell
.\LiveTranslate.exe --setup-models
.\LiveTranslate.exe
```

Сборка оставляет консоль для диагностики и установки моделей. Это portable onedir,
не установщик и не подписанный бинарник. Модели не входят в артефакт; первая
настройка требует сети. SmartScreen может предупреждать о неподписанном exe.
Статус фактического запуска CI смотрите во вкладке Actions; наличие workflow
само по себе не означает успешную сборку.

## Структура

```text
src/livetranslate/
  audio.py         WASAPI, ресэмплинг, VAD, ограниченная очередь
  core.py          сегментация, режимы, учебные правила
  engine.py        QThread распознавания и перевода
  translation.py   Argos и установка моделей
  assistant.py     локальный Ollama, валидация ответа
  windows.py       display affinity и RegisterHotKey
  ui.py            окно, Overlay, трей, темы, произношение
  __main__.py      CLI и запуск
 tests/            переносимые тесты и Qt smoke test
```
